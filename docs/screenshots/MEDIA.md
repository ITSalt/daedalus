# Animated screenshots

Sped-up recordings of the same invented installation the still screenshots are taken over. Each is 1200 px wide, 15 frames a second, with a palette of its own.

| File | Where in the README | What it shows |
|---|---|---|
| `browser.gif` | the picture at the top | The agent's own browser, live, with the actions it took: the operator takes control, leaves a note for the agent and gives the browser back. |
| `session.gif` | How it looks — a session | A session: the agent's answer with its checks and the files it sent, the steps it took, and the site it built in the panel's browser. |
| `orchestration.gif` | How it looks — orchestration | The main orchestrator's chat: dispatches to project orchestrators and their progress, questions answered in the Questions tab and sent, then a project's team of staff. |
| `phone.gif` | How it looks — on a phone | The same app on a phone: the agents, a session with its answer, the mode sheet, and the agent's browser. |
| `selfdev.gif` | Self-development | Changes: a pull request the agent opened against its own code, its summary and diff, approved in the app, merged, and the rebuild started. |
